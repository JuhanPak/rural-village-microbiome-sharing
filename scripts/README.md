# Rural village microbiome sharing

Analysis code associated with the manuscript:

**Rural villages structure gut microbiome sharing across nested spatial scales**

## Code

The `scripts/` directory contains the custom R Markdown scripts used for
the statistical analyses and figure generation reported in the manuscript.

Analyses were performed primarily using R 4.4.1.

Raw 16S rRNA gene amplicon sequencing data are available from the
NCBI Sequence Read Archive under BioProject PRJNA1456216.
